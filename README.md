## Sobre mí

Soy **Aurelio — Synnergy Dev**, desarrollador web y especialista en marketing. Vivo y trabajo desde **Cuba**, donde construyo soluciones digitales con una perspectiva práctica: tecnología ligera, estrategia clara y comunicación que ayude a tomar mejores decisiones.

Me interesa conectar dos mundos que a menudo se trabajan por separado:

> **La web debe verse bien, funcionar con fiabilidad y tener un propósito comercial comprensible.**

Mi trabajo combina desarrollo frontend, identidad de marca, estrategia de marketing, automatización y creación de contenidos. Estoy construyendo Synnergy Lab paso a paso, con recursos limitados pero con una visión amplia: ayudar a negocios y profesionales a ordenar su presencia digital y convertirla en un sistema más útil y sostenible.

## El proyecto

Este repositorio contiene el sitio web de **Synnergy Lab**, una agencia de estrategia, automatización, marketing y servicios creativos.

La web está pensada para explicar con claridad cómo una marca puede pasar de tener piezas digitales aisladas a contar con un sistema conectado:

| Fase | Propósito |
| --- | --- |
| **Diagnóstico** | Entender la situación digital, el mercado y las oportunidades reales. |
| **Marca** | Ordenar el posicionamiento, la propuesta de valor, la voz y la identidad. |
| **Sistema de ventas** | Conectar oferta, recorrido del cliente y puntos de conversión. |
| **Campaña** | Coordinar una iniciativa comercial concreta con objetivos medibles. |
| **Optimización** | Aprender de los datos y mejorar el sistema con criterio. |

El objetivo no es llenar la web de promesas, sino crear una base honesta para presentar servicios, documentar proyectos y construir confianza.

## Visión

Quiero que Synnergy Lab sea una agencia capaz de trabajar con profundidad sin perder la sencillez. Una agencia que traduzca problemas complejos en decisiones concretas y que use la tecnología para dar más claridad, autonomía y capacidad de acción a sus clientes.

Esta web es también un laboratorio público de aprendizaje. Aquí pruebo y documento formas de:

- diseñar experiencias bilingües y accesibles;
- construir sitios rápidos con dependencias mínimas;
- organizar contenido y SEO desde la arquitectura;
- conectar estrategia, diseño, código y medición;
- trabajar con honestidad sobre lo que está validado, lo que está en prototipo y lo que todavía debe demostrarse.

### Decisiones de diseño

- **Español por defecto:** la raíz dirige a `/es/`; la versión inglesa vive en `/en/`.
- **URLs limpias:** cada idioma tiene rutas canónicas y consistentes.
- **Identidad visual:** azul profundo `#0a2e5a`, morado `#7b1ba4` y neutros claros.
- **Tipografía:** Exo 2 para titulares y Montserrat para el texto de lectura.
- **Contenido responsable:** no se inventan métricas, casos de éxito ni resultados.
